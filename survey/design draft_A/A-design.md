# SPACELOG design.md (시안 A · 태스크 테스트용 · 2026-11-26)

`SPACELOG_Prototype v2` / `handoff/SPACELOG_A.html` 기준입니다. 시안 A/B 태스크 테스트에서 두 시안의 조건을 맞추기 위한 문서입니다. 14절(태스크 테스트 조건)을 먼저 보고, 1~13절은 화면 값을 맞출 때 참고하세요.

## 1. 방향

- 우주 톤의 기록 아카이브. 기본은 **다크 모드**, 사용자가 브라이트 모드로 바꿀 수 있습니다.
- UI는 거의 보이지 않게. 기록 내용과 그룹(행성) 이미지가 주인공입니다.
- 강조색은 한 번에 하나. 화면 공통 강조는 `#0066cc`, 그룹 안에서는 그 그룹의 색.
- 보기 방식은 두 가지: **1D(문서 목록)** 와 **3D(우주 공간)**. 같은 데이터를 다른 방식으로 봅니다.
- 그라디언트는 브라이트 모드 3D 배경 한 곳에만 씁니다. 네온 글로우, 패턴, 이모지, 색 있는 테두리 강조는 쓰지 않습니다.

## 2. 용어

| 화면에 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 기록 | 저장한 파일·링크·메모 하나 | 별 |
| 그룹 | 기록을 묶는 주제. 3D에서는 행성 모양 | 행성, 카테고리 |
| 분류 안 된 기록 | 그룹을 정하지 않은 기록 (성운 모양) | |
| 모아보기 | 여러 그룹의 기록을 골라 한곳에 모은 것 | 이어보기, 별자리 |
| 리마인드 | N일 전 오늘 넣은 기록을 다시 보여 주는 것 | 재발견 혜성 |
| 우주먼지 | 도움말 챗봇 이름 | |

## 5. 배치

### 넓은 화면 (720px 이상)

```
┌ 목록 창 (좌상단) ┐                 ┌ 기간 바 (우상단) ┐
│ SPACELOG    [접기]│   [검색 44px]    │ ‹ 직접 지정 › 오늘 이번주 이번달 전체 │
│ 우주선장님 로그아웃 ☀ ⚙ │                 └──────────────────┘
│ [ 1D | 3D ]      │
│ ─────────────    │        (1D: 문서 목록 / 3D: 우주)
│ 그룹 바로가기 n   │
│  + 새 그룹        │
│  전체 보기        │
│  그룹 …           │
│ 기록 n ›          │
│ 처음이라면 이렇게 날아요 ⌄ │
└──────────────────┘
              [ + 기록 넣기 · 끌어다 놓기 · 붙여넣기 ][우주먼지]
```

- 목록 창: 좌상단 `left 24px, top 24px`, 폭 300px, 모서리 18px, 안쪽 16px.
  - SPACELOG ~ 1D/3D 아래 구분선까지 **고정**, 그 아래만 스크롤.
  - 스크롤바는 숨기고, 더 내릴 내용이 있으면 아래 64px 그라데이션(창 색 → 투명) + 가운데 `⌄` 버튼. 누르면 아래로 이동.
  - 접기: 아이콘만 남는 세로 줄로 줄어듭니다.
  - 다른 창이 열린 뒤 바깥을 누르면 투명도 50%, 마우스를 올리면 100%.
- 기간 바: 우상단 `top 24px`, 필요한 너비만. 칩 4개는 76px, 공간이 모자랄 때만 44px까지 줄어듭니다. ‘‹ 직접 지정 ›’은 줄지 않습니다. 직접 지정을 누르면 아래로 날짜 줄이 열립니다.
- 검색: 1D·3D 모두 같은 자리·크기(높이 44px, 알약). 기간 바 높이 가운데에 맞춥니다.
- 하단: ‘+ 기록 넣기’와 우주먼지를 한 세트로 화면 가운데 정렬, 아래 24px.

### 좁은 화면 (720px 미만)

- 목록 창 → **상단바** 한 줄: 왼쪽 목록 열기 아이콘 · 그룹 · 밝기 · 검색 아이콘, 가운데 기간 선택.
- 검색 아이콘을 누르면 기간 선택 자리에 검색창이 대신 나옵니다.
- 상단바 아래로 겹치는 내용이 헷갈리지 않게, 위쪽에 바탕색 그라데이션을 살짝 깝니다.
- 그룹을 고르면 목록이 자동으로 닫힙니다. 행성 창·상세 창은 상단바 아래(72px)부터 엽니다.

## 6. 1D와 3D

### 1D (문서 목록)
- 페이지 전체가 스크롤됩니다. 상세 기록도 창 안 스크롤 없이 아래로 길어집니다.
- 목록 열: 체크 · 제목·종류 · 그룹(색 점 + 이름) · 넣은 날 · 지난 날.
- 위쪽: ‘분류되지 않은 기록 n개’ 카드(빠른 분류 ⌄ · 상세보기) → 기록 n개 + [전체 보기 | 그룹별 보기] 스위치 + 휴지통.
- 목록 창의 그룹을 누르면 가운데 목록이 그 그룹으로 바뀝니다. 그룹 목록은 처음부터 펼쳐져 있습니다.
- 그룹을 바꿔도 제목과 목록 위치가 위아래로 움직이지 않습니다.

### 3D (우주 공간)
- 그룹 = 행성(실사 이미지 + 색 필터). 모양: 기본, 고리, 성운, 지구, 탐사선.
- 행성 위에 그룹 이름, 아래에 ‘기록 n’(분류 안 된 기록은 ‘조각 n’).
- 우주인 캐릭터(실사 PNG, 3등신)가 방향별 이미지로 움직입니다.
- 행성을 누르면 날아가 착륙(약 800ms) → 오른쪽에 그룹 창. 기록을 누르면 가운데 상세 창.
- 상세 창이 열려 있어도 목록 창에서 다른 그룹으로 바로 이동할 수 있습니다.
- 배경 음악은 3D에서만, 기본은 꺼짐.

## 8. 그림자·블러·움직임

- 그림자: `rgba(0,0,0,0.22) 3px 5px 30px` 하나. 떠 있는 창·토스트에만.
- 블러: `backdrop-filter: saturate(180%) blur(20px)`. 떠 있는 창에만.
- 누름: 모든 버튼·칩 `scale(0.95)`, `200ms cubic-bezier(0.25,0.1,0.25,1)`.
- 호버: 목록 행·그룹 행·‘+ 새 그룹’·FAQ 행에 3절 호버 색. 행 **전체 폭**으로 칠합니다 (좌우 여백 없음).
- 포커스: `2px solid #0071e3`, 2px 띄움.
- 전환: 짧은 페이드와 색 변화만. 깜빡이거나 튀는 움직임 없음.

## 9. 구성 요소

- **주 버튼:** 알약, 면 `#0066cc`(그룹 안에서는 `base`), 흰 글자, 높이 36~44px.
- **보조 버튼:** 알약, 투명 면 + 버튼 테두리.
- **아이콘 버튼:** 원형 32px, 테두리만. 목록 창 상단: 밝기(해/달), 설정.
- **스위치(분할 알약):** 1D/3D, 전체 보기/그룹별 보기, 기간. 바깥 알약 + 안쪽 4px, 선택 칸은 3절 스위치 색.
- **체크박스:** 16px, 모서리 5px. 끔 `1.5px solid rgba(255,255,255,0.32)`(브라이트 `#aeaeb2`), 켬 `#0066cc`. 체크박스와 옆 아이콘 사이 12px 이상.
- **메모:** 저장된 메모는 잠겨 있고 ‘수정하기’를 눌러야 고칩니다. 메모가 없으면 바로 쓰고 ‘저장하기’.
- **덧붙인 기록:** 상세 아래 댓글형. ‘2026년 11월 24일 14:05’ + 편집·삭제. Enter 저장, Shift+Enter 줄바꿈.
- **링크:** 링크가 있으면 ‘링크 열기 (도메인)’, 없으면 점선 ‘링크 추가하기’.
- **토스트:** 화면 아래 가운데, 흰 면, `#1d1d1f` 글자, 약 2.4초.
- **확인:** 삭제·합치기는 같은 창 안에서 한 번 더 묻습니다. 브라우저 확인창 쓰지 않음.

### 우주먼지 (챗봇)
- 흰 빛무리 원형 버튼. ‘기록 넣기’ 오른쪽, 끌어서 옮길 수 있음.
- 창 폭 440px(좁은 화면 400px). 탭: 홈(자주 묻는 질문) · 대화 · 설정.
- 자주 묻는 질문은 토글로 답을 펼치고, 캡처 이미지를 ‹ › 로 넘깁니다(설명 글 없음).
- 답변 카드 아래 출처 기록 카드, ‘기록으로 저장’(다시 누르면 취소).
- 창을 띄운 채로도 화면 아래 버튼과 겹치지 않습니다.

## 10. 아이콘

- Lucide만: `https://unpkg.com/lucide-static@0.469.0/icons/<이름>.svg`, 14~18px.
- 다크 `filter: invert(1)` + 투명도 0.7~0.85, 브라이트 `filter: none`.
- 이모지·직접 그린 그림 없음. 로고는 글자 ‘SPACELOG’.

## 11. 문구

- 차분한 해요체, 짧게. 느낌표·과장 없음.
- 버튼 1~3어절, 동작 먼저: ‘기록 넣기’, ‘저장하기’, ‘수정하기’, ‘상세보기’, ‘뒤로가기’.
- 날짜와 ‘N일 전’은 기록을 넣은 시각 기준.
- 준비 안 된 기능은 안내만: ‘프로필 설정은 준비 중이에요.’
- 빈 상태: ‘끌어다 놓으면 기록이 됩니다.’ / ‘클립보드에서 바로 붙여넣을 수도 있어요.’

## 12. 키보드 (3D)

- W·A·S·D 이동, Space 상승, Shift 하강, 드래그 시점, 휠 앞뒤, E 착륙.
- Esc는 한 단계씩 닫기: 상세 → 그룹 창 → 우주.
- 입력칸에 포커스가 있으면 비행 키를 받지 않습니다.

## 13. 하지 말 것

- 브라이트 모드에서 연한 `light` 색을 글자로 쓰기
- 스크롤바 노출 (목록 창·오늘 기록은 숨기고 ⌄ 로 안내)
- 한 화면에 강조색 두 개 이상, 카드 그림자
- 이모지, 느낌표, 굵기 500, Pretendard 외 서체
- 화면을 오가며 위치가 위아래로 흔들리는 배치

## 14. 태스크 테스트 조건 (시안 A/B 공통)

두 시안의 차이가 **보기 방식과 디자인**에서만 나오도록, 아래 조건은 A와 B가 똑같이 맞춥니다.

### 태스크와 화면

| 태스크 | 참가자에게 보여 줄 화면 | 완료로 보는 순간 |
