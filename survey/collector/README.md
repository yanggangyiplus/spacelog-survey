# collector

데스크톱 수집앱을 웹에서 흉내 낸 테스트용 화면입니다. 바탕화면 위에 작은 브라우저 창과 파일이 있고, 우주 비행사가 그 밖에 떠 있습니다.

- 캐릭터는 주소의 `?design=A|B`로 고릅니다. `astro-A.webp`는 시안 A 묶음 파일의 `assets/astro3-01.png`, `astro-B.png`는 시안 B '캐릭터 꾸미기' 미리보기의 정면 모습을 옮긴 것입니다. 시안의 캐릭터가 바뀌면 이 두 파일을 바꿉니다.

- 되는 것: 캐릭터 끌어 옮기기 · 모서리로 크기 바꾸기(위치 저장, 화면 밖 보정), 파일 · 링크 · 글 끌어다 놓기, 붙여넣기, 받아먹는 모션과 "바쁨" 표시, 키워드로 그룹 배정, 넣은 뒤 그룹 바꾸기와 한 줄 메모, 메뉴, "지금 내 생각" 입력창, 캡처(영역을 끌어서 선택, 고른 부분이 사진으로 남음), 파일 선택, 단축키 Cmd/Ctrl+Shift+Space.
- 안내만 뜨는 것: 우주 열기, 우주먼지, 분석 대기 다시 시도, 앱 종료. 탐사 시작/종료는 넣은 개수만 셉니다.
- AI 요약은 부르지 않습니다. 요약 칸에는 내용 앞부분을 보여 줍니다.
- 용어는 `design draft_A/A-design.md` 2절(기록, 그룹, 우주먼지)을 따릅니다.
- 그룹 목록은 `../data.js`(빌드가 `shared-data/data.json`으로 만듦)에서 읽고, 저장한 기록은 부모 창에 `postMessage`로 넘깁니다.
