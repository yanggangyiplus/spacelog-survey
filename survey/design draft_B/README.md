# spaceLog 비교 테스트 화면

디자인 비교 테스트(A/B)에서 쓰는 spaceLog 쪽 화면입니다. 서버와 DB 없이 더미 데이터로 돌아갑니다.

## 파일

| 파일 | 내용 |
|---|---|
| `spacelog-home.html` | 테스트 홈: 기록 목록, 행성 고르기, 기간, 자주 찾음, 상세, 흉내 챗봇. 손으로 짠 정적 HTML이에요. |
| `universe.html` | 3D 우주: 실제 앱(`web/`)을 더미 데이터로 빌드한 것. JS, CSS, 서체가 모두 이 파일 하나에 들어 있어요(약 4.9MB). |
| `data.js` | 두 화면이 함께 쓰는 더미 데이터(행성 7개, 기록 11개)와 흉내 챗봇 답. |

세 파일은 **같은 폴더**에 있어야 해요.

## 여는 법

- `spacelog-home.html`을 브라우저로 열면 돼요. 서버가 필요 없어요.
- 홈의 "우주로 들어가기" → `universe.html`(블랙홀 전환 후 우주), 우주의 "← 홈" → 홈으로 돌아와요.
- 두 화면은 상태를 공유해요(`sessionStorage`). 홈에서 켠 별표, 우주에서 옮긴 별이 서로 보여요.
- **처음 상태로 되돌리기:** 탭을 닫았다 다시 열거나, 주소 끝에 `?reset`을 붙여 열어요(`spacelog-home.html?reset`).
- 로그인한 상태로 시작해요(시연용 계정 "우주선장"). 로그아웃하면 홈으로 돌아가요.

## 실제처럼 동작하는 것 / 안 하는 것

- 동작: 우주 비행·착륙, 행성/별 목록, ⋯ 메뉴(꾸미기·옮기기·지우기), 기록하기, 캐릭터 꾸미기, 챗봇(미리 써 둔 답과 근거), 계정 설정(이름).
- 안내만 뜸: 원본 열기, 폴더에서 보기(보관함이 없어요). 파일 첨부는 이름만 남아요.
- 챗봇은 AI를 부르지 않아요. `data.js`의 `chat.answers`에서 질문 낱말에 맞는 답을 골라요. 참가자 모두 같은 답을 받아요. 과제용 질문이 정해지면 여기에 답을 더해 주세요.

## 다시 빌드하기 (`universe.html`)

실제 앱 코드(`web/src/`)를 고친 뒤 테스트 화면에도 반영하려면 프로젝트 폴더 맨 위에서:

```
npm install
npm run build:abtest
```

- 설정: `vite.abtest.config.js`. 실제 앱의 `web/src/api.js`만 가짜(`web/abtest/mockApi.js`)로 바꿔 끼우고, 결과를 `universe.html` 하나로 묶어요.
- 시작점: `web/abtest/main.js`(열리면 바로 우주로, "← 홈"은 테스트 홈으로).
- 실제 앱 코드와 일반 빌드(`npm run build`)에는 영향이 없어요.

## 링크로 배포할 때

이 폴더를 그대로 정적 호스팅(Vercel, GitHub Pages, Netlify 등)에 올리면 돼요. 서버 설정은 필요 없어요. 시작 주소는 `spacelog-home.html`이에요(호스팅이 `index.html`을 첫 페이지로 쓰면 이름을 바꾸고, `universe.html` 안의 돌아가기 주소 `spacelog-home.html`도 함께 바꿔 주세요. `web/abtest/main.js`의 `HOME` 값을 고친 뒤 다시 빌드하면 돼요).
